# Synthetic Customer Success Dataset

This dataset is intentionally small and synthetic. It is designed to let candidates run an end-to-end AI workflow without connecting to real CRM, support, product-usage, or call-recording systems.

Files:
- accounts.csv: Account-level portfolio context and health signals.
- usage_events.csv: Recent product-usage signals.
- support_tickets.csv: Inbound account-specific support issues.
- call_notes.csv: Prior customer conversation context.
- scheduled_checkins.csv: Upcoming customer check-ins.
- junior_outputs.csv: Draft work outputs that require quality review.
- quality_standards.csv: Standards for reviewing outputs.

Candidates may create additional mock examples if needed, but the main workflow should run on the provided data.
